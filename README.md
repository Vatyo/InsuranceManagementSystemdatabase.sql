# Insurance Management System Database 🏥

A relational database built with MySQL for managing insurance company operations.

 📋 Database Structure
- customers — customer personal information
- policies — insurance policies
- policy_types — types of insurance policies
- claims — insurance claims
- claim_audit — audit trail for claims
- payments — payment records
- staff — staff information
- v_customer_policies_claims — view: customer policies and claims
- v_customers_public — view: public customer data
- v_policy_claim_counts — view: policy claim statistics
